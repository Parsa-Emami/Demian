# Phase 12 — Daily & weekly missions

Separate nonfinancial mission ledger, version daily-weekly-missions-v1. One positive server-replay-verified run started in a Tehran calendar day gives 5 XP (max seven days). Three distinct active days gives 15 XP once; two distinct eligible games give 10 XP once; one adaptive goal gives 15 XP once. Maximum 75 mission XP per week plus the unchanged 225 base loyalty XP, lifetime total max 300 per account per week. No repeat-run/score/claim farming. Mission participation by game is displayed independently; adaptive target is highest prior sealed same-game/rule-version score + max(25,ceil(5%)), after three prior weeks, using only results sealed by the weekly start so late seals cannot lower that target. Final adaptive XP additionally requires the current PersonalProgress breakthrough badge to prevent repeated rewards from an older target. A new rules version recalibrates. No target is invented before a ranked version lock; inactive or unverified games cannot create final XP.

Live read-only preview uses verified runs joined to current weekly best entries, phone ownership before start, positive score, server completion time and game/version identity. Time buckets are based on trusted start time, midnight Asia/Tehran; a replay finishing after midnight can still qualify for the day of start. Final source is restricted to the sealed-snapshot PersonalProgress projection, not client input. 7 indexed grouped queries per chunk, not all raw replay data. Source digest, unique per player/period, integer components, atomic existing serialized settlement. Mission XP computed separately from v1 base ledger; no historical rewrite or backfill of already sealed periods, no additional coupons. Late seals can still earn base mission participation, but not an adaptive badge denied by progress. No client write endpoint. XP is private and nontransferable.
