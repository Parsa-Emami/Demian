# Hotfix اعتبارسنجی CI نسخه 8.1.5

Runner تست JavaScript از نسخه 8.1.4 تمام فایل‌های `.test.js` را بازگشتی پیدا می‌کند. Validatorهای تاریخی هنوز انتظار داشتند مسیر هر گروه به‌صورت wildcard داخل `package.json` نوشته شده باشد. این Hotfix یک قرارداد مشترک برای تشخیص Runner بازگشتی اضافه و Validatorهای فازهای ۴ تا ۸ را با آن هم‌راستا می‌کند.
