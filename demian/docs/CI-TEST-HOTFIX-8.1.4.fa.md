# اصلاح تست آپلود کاراکتر و اجرای تست JavaScript در ویندوز — 8.1.4

## مشکل تست Laravel

Fixture تست آپلود فقط Animation مربوط به `idle` را می‌ساخت، اما قرارداد Atlas پروژه
Animationهای `idle`، `walk`، `run`، `jump`، `attack` و `win` را الزامی می‌داند.
به همین دلیل درخواست باید 422 می‌شد و انتظار 201 در تست قدیمی نادرست بود.

در نسخه 8.1.4 Fixture معتبر کامل شده و یک تست مستقل نیز اضافه شده است که Atlas ناقص را
عمداً با پاسخ 422 بررسی می‌کند.

## مشکل Windows

Shell ویندوز wildcardهای `tests/js/*.test.js` را برای Node باز نمی‌کند. اسکریپت جدید
`tools/run_js_tests.mjs` تمام فایل‌های `.test.js` را به‌صورت بازگشتی کشف می‌کند و مسیرهای
صریح را به `node --test` می‌دهد؛ بنابراین همان فرمان روی Windows، Linux و macOS اجرا می‌شود.
