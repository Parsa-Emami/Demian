# فاز ۹ — شبکه، همگام‌سازی و مشاهده‌پذیری

فاز ۹ یک مرز مستقل برای اتصال شبکه اضافه می‌کند. `NetworkTransport` مسئول چرخه‌ی اتصال و پیام‌های معنایی است و به WebSocket خاصی وابسته نیست؛ `SessionReplication` فقط Snapshotهای دارای sequence معتبر را می‌پذیرد و برای رندر، interpolation محدود انجام می‌دهد؛ `TelemetryBuffer` نیز رویدادهای زمان‌دار را با سقف حافظه نگه می‌دارد. هیچ‌کدام از این لایه‌ها به Renderer، DOM یا منطق اقتصاد وابسته نیستند و در صورت قطع شبکه، بازی محلی همچنان قابل ادامه است.
