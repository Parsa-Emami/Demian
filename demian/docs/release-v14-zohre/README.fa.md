# زهره در دمیان

زهره (`ZOHRE / زهره`) بعد از مرجان در فهرست انتخاب کاراکتر قرار دارد. موی قهوه‌ای تیره، پلیور قرمز یقه‌هفت، یقهٔ سفید، شلوار زغالی و کفش مشکی از تصویر مرجع زهره گرفته شده‌اند. تناسب بدن، ژست‌های اصلی و محور پا `(0.5, 0.94)` بر اساس دریا در V14 تنظیم شده‌اند.

سه شیت مستقل با همان پوشش و تناسب تولید شده‌اند. شیت اول هشت جهت ایستادن، چشمک و حرکت برد را دارد. شیت دوم ژست‌های راه‌رفتن، دویدن، پرش و فرود را دارد. شیت سوم چرخهٔ پایین سرخوردن را دارد. نسخه‌های چپ و راست حرکت طبق نگاشت جهت‌های V14 در بازی فراخوانی می‌شوند. فایل‌های منبع و شناسهٔ SHA-256 ورودی‌ها در [source-v14](../../public/assets/characters/zohre/source-v14) ثبت شده‌اند.

## بازسازی

دستورها از پوشهٔ `demian` اجرا می‌شوند.

```sh
python3 tools/build_character_pack_v14.py --characters zohre
python3 tools/build_runtime_character_packs.py --characters zohre --report docs/release-v14-zohre/runtime-packs.json
npm run validate:characters:v14
npm run build:static
```

## آزمون‌ها

- هر شش نسخهٔ اطلس زهره و مجموع ۱۴۴ جفت اطلس و تصویر برای ۲۴ کاراکتر اعتبارسنجی شدند. ارتفاع سرخوردن زهره در بلندترین فریم ۴۵٫۳۱ پیکسل از حد ۴۶ پیکسل بود. اندازه و تعداد سلول‌های نسخه‌های اجرایی در [runtime-packs.json](runtime-packs.json) ثبت شده است.
- در Chromium با رندر نرم‌افزاری و نماهای ۳۹۰×۸۴۴ و ۱۴۴۰×۹۰۰، کارت زهره و ماندگاری انتخاب پس از بارگذاری دوباره بررسی شد. اطلس زهره در Open World، Dino Run، After Hours و Café Rush بارگذاری شد. راه‌رفتن و دویدن در Open World و پرش و سرخوردن زیر مانع پرنده با لمس و کیبورد در Dino Run پاس شدند.
- ۹۰۸ تست JavaScript و ۳۵۳ تست PHPUnit با SQLite پاس شدند. اعتبارسنجی خروجی PWA، لایه‌های رابط و سازگاری تبِ باز از نسخهٔ قبل هم پاس شد. شناسهٔ خروجی استاتیک `52f37c5a9b75a31c` است.
- آزمون روی گوشی فیزیکی در [Issue #117](https://github.com/Parsa-Emami/Demian/issues/117) پیگیری می‌شود.
