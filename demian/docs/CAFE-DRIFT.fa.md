# Café Drift · دریفت سینی

کافه دریفت از منوی بازی دمیان اجرا می‌شود. هر دور ۴۵ ثانیه طول می‌کشد یا با شکستن سومین فنجان تمام می‌شود. بازیکن با کشیدن انگشت روی مسیر، کلیدهای جهت یا دسته سینی را جابه‌جا می‌کند. جاخالی نزدیک و دانهٔ طلایی کمبو را تا ×۵ افزایش می‌دهند. برخورد یا عبور عادی زنجیره را قطع می‌کند. فنجان‌های سالم در پایان شیفت امتیاز اضافه دارند.

## ثبت رقابتی

- مسیر همهٔ بازیکنان در هر هفته ثابت است و شنبه ساعت ۰۰:۰۰ تهران تغییر می‌کند.
- درخواست آغاز، شناسهٔ دور، بذر، نسخهٔ قواعد و انقضا را از سرور می‌گیرد. مدرک پایانی فقط تعداد تیک و تغییرات فرمان جهت را دارد.
- مرورگر و PHP یک مدل عددصحیح با فرکانس ۶۰ هرتز اجرا می‌کنند. PHP سرعت، برخورد، جاخالی، دانه، کمبو، پایان دور و امتیاز را دوباره محاسبه می‌کند.
- API فرمت، اندازه، دامنه، ترتیب و زمان ورودی‌ها، مالکیت دور و انقضا را بررسی می‌کند. قفل هفته و ثبت تراکنشی مشترک دمیان از ثبت تکراری مدرک یا جایگزینی رکورد با امتیاز ضعیف‌تر جلوگیری می‌کنند.
- توقف و تغییر زبانه در رابط بازی، دور را به تمرین تبدیل می‌کند. تمرین و قطع اتصال هنگام شروع فقط رکورد دستگاه دارند. قطع اتصال بعد از یک دور رقابتی از صف بازپخش موجود برای ارسال دوباره استفاده می‌کند.
- جدول هفتگی بازی مستقل است و فقط رکوردهای تأییدشده را می‌خواند. گزینهٔ `DEMIAN_ARCADE_DRIFT_RANKED_ENABLED` امکان توقف پذیرش رقابتی را فراهم می‌کند. پایش اختیاری ضدتقلب موجود می‌تواند شباهت بازپخش‌ها و رفتار غیرعادی را برای بررسی اپراتور گزارش کند. صدور کوپن از این بازی فعال نیست.

## بررسی

بستهٔ استاتیک و کاتالوگ آفلاین همراه سورس به‌روز شده‌اند. تست‌های مدل، ۱۰۴ مسیر هفتگی و مکانیک برخورد، امتیاز و پایان را پوشش می‌دهند. تست‌های Laravel خروجی ۳۲ بازپخش را با JavaScript مقایسه می‌کنند و مسیر HTTP برای امتیاز جعلی، مدرک ناسازگار، حساب دیگر، انقضا، ارسال دوباره و لیدربورد را پوشش می‌دهند.

در Chromium 150 با رندر نرم‌افزاری، دور دسکتاپ ۱۴۴۰×۹۰۰ با کیبورد و ثبت واقعی رکورد در API و لیدربورد Laravel محلی پاس شد. لمس، توقف و ادامه و چیدمان HUD در پروفایل‌های شبیه‌سازی‌شدهٔ ۳۲۰×۵۶۸، ۳۹۰×۸۴۴ و ۸۴۴×۳۹۰ هم پاس شدند.

برای QA مرورگر روی نسخهٔ Laravel محلی از `node tools/check_cafe_drift.mjs` استفاده کنید. `DEMIAN_DRIFT_QA_URL` آدرس محلی، `DEMIAN_BROWSER_EXECUTABLE` مسیر اختیاری Chromium و `DEMIAN_DRIFT_QA_OUTPUT` مسیر خروجی تصاویر را تعیین می‌کند.

راهنماهای پروژهٔ به‌کاررفته در این تغییر `threejs-scene-setup`، `input-systems`، `game-feel`، `game-ui-ux` و `physics-tuning` بودند.
