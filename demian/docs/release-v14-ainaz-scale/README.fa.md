# اصلاح اندازهٔ آیناز در حرکت

قد واقعی تصویر آیناز در شیت حرکت، با مقیاس حالت ایستاده یکسان نبود. تشخیص رنگ پوست، دست یا بخش‌هایی از لباس را به محدودهٔ صورت وصل می‌کرد و ضریب کالیبراسیون حرکت را کوچک‌تر می‌ساخت. اندازهٔ منطقی بازی همچنان ۳٫۷۵ واحد بود؛ بررسی قبلی فقط اندازهٔ سلول و صحت ارجاع فریم‌ها را می‌سنجید.

اکنون پوزهای مرجع با قد ایستاده در `source-v14/layout.json` مشخص هستند. ابزار ساخت، برای هر کلیپ یک ضریب یکنواخت از ارتفاع این پوزها محاسبه می‌کند. این ضریب در تمام فریم‌های همان کلیپ ثابت است و نسبت عرض به ارتفاع تصویر حفظ می‌شود. حالت فرود با پوزهای ایستادهٔ انتهای کلیپ کالیبره می‌شود تا خم‌شدن زانوها طبیعی باقی بماند. محدودهٔ نمونه‌برداری صورت آیناز نیز به بخش بالایی بدن محدود شده است.

سایه و اندازهٔ مشترک بازی ثابت هستند. حرکت آیناز اکنون با مقیاس ایستادن و بقیهٔ کاراکترها هماهنگ است. اندازه‌های زیر از محدودهٔ آلفای واقعی تصاویر runtime اندازه‌گیری شده‌اند:

| حالت | قد نمایشی قبلی | قد نمایشی اصلاح‌شده |
| --- | ---: | ---: |
| ایستادن | 3.7946 | 3.7946 |
| راه‌رفتن | 2.3996 | 3.7946 |
| دویدن | 2.2321 | 3.7946 |
| دویدن سریع | 2.2321 | 3.7946 |
| جشن | 2.0089 | 3.7946 |

تفاوت جزئی با هدف ۳٫۷۵ واحد، ناشی از نمونه‌برداری پیکسل و آستانهٔ آلفاست. سرخوردن، پوز کم‌ارتفاع مستقل دارد و همچنان از زیر پرنده عبور می‌کند.

اعتبارسنجی اکنون ارتفاع واقعی آلفای idle، walk، run و sprint را برای هر هشت کاراکتر و هر پنج نوع اطلس کنترل می‌کند. کلیپ‌های کالیبره‌شدهٔ آیناز باید در محدودهٔ ۹۶ تا ۱۰۵ درصد قد استاندارد باشند. محدودهٔ سایر تصاویر، اختلاف طبیعی پوز و نمونه‌برداری را در نظر می‌گیرد. تست مرورگر، PNG بارگذاری‌شده و اندازهٔ نمایش واقعی را در ابعاد 390×844 و 1440×900 بررسی می‌کند؛ اندازهٔ راه‌رفتن و دویدن و ضریب ثابت بدن نیز ثبت می‌شوند.

فایل‌های شیت، اطلس و تنظیمات در سورس و `playable` یکسان هستند. هش جدید تصاویر، مسیر کش‌شکن موجود را فعال می‌کند. تصاویر منابع اصلی، ساختار دیتابیس، migrationها، `.env` و Dockerfile تغییری نکرده‌اند.

نتایج عددی در `body-scale-measurements.json` و نتیجهٔ آزمون مرورگر در `browser-checks.json` قرار دارند. خلاصهٔ بررسی‌ها در `verification.json` ثبت شده است. گوشی فیزیکی اندازه‌گیری نشده؛ ابعاد موبایل در Chromium شبیه‌سازی شده‌اند.

برای بازسازی، از ابزار موجود استفاده کنید:

```bash
python3 tools/build_character_pack_v14.py --characters ainaz
python3 tools/build_runtime_character_packs.py --characters ainaz --report docs/release-v14-ainaz-scale/runtime-packs.json
npm run validate:characters:v14
npm run test:ci
npm run build
node tools/export_static.mjs --out=../playable
```
