# حسین در دمیان

حسین با عینک خلبانی، موهای مشکی رو به عقب، سبیل و ریش مرتب، پیراهن دکمه‌دار تیره با آستین تا مچ، شلوار مشکی، کمربند و کفش مشکی از روی مرجع کاربر ساخته شده است. او در فهرست مشترک شخصیت‌ها قابل انتخاب است و انتخابش در کافه، رانر و پس از بارگذاری مجدد حفظ می‌شود. جایگاه قدیمی و خالی حسین با بستهٔ واقعی V14 جایگزین شده است.

ارتفاع استاندارد بدن ۳٫۷۵ واحد و محور کف پا ۰٫۹۴، مطابق سایر شخصیت‌ها است. مقیاس هر کلیپ حرکت به‌صورت یکنواخت کالیبره می‌شود. بسته شامل ۶۲ حالت اصلی انتخاب‌شده و ۶۷۲ نام فریم انیمیشن با ۲۴ اکشن و نام مستعار است. شش نسخهٔ desktop، mobile، compact، runtime، lite و detail ارسال شده‌اند؛ runtime و lite به‌ترتیب ۳۱۶ و ۲۳۹ سلول تصویری دارند. چرخهٔ سرخوردن از شش حالت کم‌ارتفاع طراحی‌شده استفاده می‌کند تا سر و بدن بدون تغییر نسبت‌ها، زیر مانع رانر قرار بگیرند.

با بازکردن «اکشن‌ها» و زدن «گفتگو»، یکی از این چهار عبارت دقیق نمایش داده می‌شود:

- غم انگیزه
- نیاز به بررسی بیشتر داره
- مجتبی دهنتو
- میزنم همرو آچه میکنم

انتخاب عبارت تصادفی است و جملهٔ قبلی بلافاصله تکرار نمی‌شود. کلید H و اکشن استاندارد speak دستهٔ بازی نیز از همین مسیر استفاده می‌کنند. حباب متن پس از ۳٫۲ ثانیه جمع می‌شود و با Canvas فعلی بازی، مقیاس صفحه و ارتفاع پرش هماهنگ است.

ساخت دوباره با `npm run build:hossein:v14` و سپس `npm run build:static` انجام می‌شود. نسخهٔ آماده در `playable/` بازسازی شده است. نصب Laravel از Seeder موجود و فهرست مشترک شخصیت‌ها استفاده می‌کند؛ `HosseinCharacterSeeder` نیز در دسترس است. اجرای Seeder مشترک، شخصیت پیش‌فرض را مطابق رفتار فعلی پروژه روی دریا تنظیم می‌کند.

۳۵۷ تست جاوااسکریپت، بررسی ۷۲ بسته برای ۱۲ شخصیت، اعتبارسنجی انتشار، لایه‌های UI، یکپارچگی ۷۷ اسکیل و بستهٔ اتمیک پاس شده‌اند. مرورگر Chromium در اندازه‌های ۳۹۰×۸۴۴ و ۱۴۴۰×۹۰۰ انتخاب از UI، پیش‌نمایش، حرکت، پرش، سرخوردن زیر مانع، شادی، هر چهار عبارت از طریق کلیک/لمس دکمهٔ گفتگو، کلید H، محوشدن حباب و حفظ انتخاب پس از reload را بررسی کرده است. برای پوشش قطعی چهار شاخه، نمونه‌های تصادفی در خود تست کنترل شده‌اند؛ انتخاب تصادفی محصول تغییری نکرده است. بررسی‌ها headless و با رندر نرم‌افزاری انجام شده‌اند؛ تلفن فیزیکی اندازه‌گیری نشده است. PHP در این محیط نصب نیست و تست‌های PHP اجرا نشده‌اند.

اسکیل‌های اعمال‌شده از نسخهٔ قفل‌شدهٔ `gamedev-skills/awesome-gamedev-agent-skills`: `router`، `threejs-scene-setup`، `create-game-assets` با مرجع `raster-pipeline` و `dialogue-systems`. موتور فعلی و three.js نسخهٔ ۰٫۱۸۵٫۱ حفظ شده‌اند. تولید تصاویر با ImageGen داخلی انجام شده و منابع و سوابق تولید در `public/assets/characters/hossein/source-v14/` و `art-prompts.json` ثبت شده‌اند.

نتایج در `verification.json`، `browser-checks.json`، `runtime-packs.json`، `js-tests.txt` و تصاویر همین پوشه قابل بررسی‌اند.
