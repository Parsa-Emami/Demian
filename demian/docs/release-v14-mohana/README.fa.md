# مهنا در دمیان

مهنا (`MOHANA / مهنا`) در فهرست انتخاب کاراکتر بلافاصله قبل از زهره قرار دارد. عینک قرمز، موهای موج‌دار قهوه‌ای، بلوز بافت سرمه‌ای، ساعت نقره‌ای و کفش‌های روشن از تصویر مرجع مهنا گرفته شده‌اند. تناسب بدن، ژست‌ها و محور پا `(0.5, 0.94)` با الگوی V14 دریا تنظیم شده‌اند.

شیت‌های منبع هشت نمای ایستادن، چشمک، راه‌رفتن، دویدن، پرش، فرود، سرخوردن و ژست پیروزی دو انگشتی را پوشش می‌دهند. نگاشت جهت‌های V14 از فریم‌های حرکت چپ و راست استفاده می‌کند. شیت‌ها، نمونهٔ نماها و SHA-256 ورودی‌های تولیدشده در [source-v14](../../public/assets/characters/mohana/source-v14) ثبت شده‌اند.

## بازسازی

دستورها را از پوشهٔ `demian` اجرا کنید.

```sh
python3 tools/build_character_pack_v14.py --characters mohana
python3 tools/build_runtime_character_packs.py --characters mohana --report docs/release-v14-mohana/runtime-packs.json
npm run validate:character-art
npm run build:static
```

## نتیجهٔ آزمون

- هر شش بستهٔ مهنا و ۱۵۶ جفت اطلس و تصویر در آزمون V14 اعتبارسنجی شدند. بیشینهٔ ارتفاع سرخوردن مهنا ۴۴٫۵۴ پیکسل با حد ۴۶ پیکسل بود. مشخصات بسته‌ها در [runtime-packs.json](runtime-packs.json) ثبت شده‌اند.
- در Chromium با رندر نرم‌افزاری و نماهای ۳۹۰×۸۴۴ و ۱۴۴۰×۹۰۰، ترتیب «مهنا، زهره، کیانا» و حفظ انتخاب پس از بارگذاری دوباره تأیید شد. مهنا در Open World، Dino Run، After Hours و Café Rush بارگذاری شد. پرش و سرخوردن زیر مانع پرنده با لمس و کیبورد در Dino Run پاس شدند.
- در Open World با بستهٔ Lite و ورودی لمسی، راه‌رفتن، دویدن، پرش و فرود مهنا آزموده شدند. بیشترین فاصلهٔ سیلوئت از محور پا در حالت زمینی ۳٫۶۵ پیکسل CSS با حد ۶ پیکسل بود.
- ۹۱۲ تست JavaScript، ۳۵۳ تست PHPUnit با SQLite و بررسی‌های خروجی PWA و تب نسخهٔ قبلی پاس شدند. شناسهٔ خروجی استاتیک `dfdbcef7f1466825` است. آزمون گوشی فیزیکی در [Issue #117](https://github.com/Parsa-Emami/Demian/issues/117) پیگیری می‌شود.
