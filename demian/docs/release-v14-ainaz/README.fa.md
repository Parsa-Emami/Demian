# آیناز — کاراکتر قابل بازی V14

اصلاح اندازهٔ راه‌رفتن و دویدن و گزارش مقایسه با مقیاس مشترک بازی در [گزارش اصلاح ابعاد](../release-v14-ainaz-scale/README.fa.md) ثبت شده است.

آیناز از سه عکس ارسالی طراحی شده است: موهای قهوه‌ای تیره با فرق جانبی، چهرهٔ آرام، پیراهن یقه‌دار کرم با آستین جمع‌شده، شلوار کرم، گردنبند و دستبند طلایی. تصاویر با ابزار داخلی `image_gen` در سبک کاراکترهای فعلی دمیان ساخته شده‌اند. شیت‌های نهایی و مشخصات ورودی‌ها در `public/assets/characters/ainaz/source-v14/` قرار دارند؛ مشخصات پرامپت‌ها در `art-prompts.json` ثبت شده است.

۸۰ پوز منبع ساخته شده و ۶۰ پوز در بسته استفاده می‌شود. ابزار موجود پروژه فریم‌های میانی را با optical flow تک‌تصویری می‌سازد. هر اطلس ۶۷۲ نام فریم و ۲۴ حالت معنایی دارد؛ بعضی حالت‌ها مانند sprint/run و salute/wave کلیپ مشترک دارند. نماهای ایستاده هشت‌جهته‌اند؛ حرکت‌ها شامل جهت چپ و راست هستند. سرخوردن از شیت کم‌ارتفاع مستقل ساخته شده است.

| بسته | اندازهٔ سلول | سلول فیزیکی |
| --- | --- | ---: |
| desktop | 144×144 | 672 |
| mobile | 112×112 | 672 |
| compact | 80×80 | 672 |
| runtime | 96×96 | 316 |
| lite | 64×64 | 239 |

نسخه‌های runtime و lite همهٔ نام فریم‌ها و زمان‌بندی انیمیشن‌ها را حفظ می‌کنند و به‌ترتیب 11.25 و 3.75 MiB حافظهٔ تصویر رمزگشایی‌شده مصرف می‌کنند. فیزیک پرش و برخورد از سیستم مشترک بازی استفاده می‌کند.

آیناز در رجیستری frontend، manifest مشترک، ابزار ساخت، فهرست انتخاب کاراکتر، کافه و Dino Run ثبت شده است. خروجی `playable` نیز به‌روزرسانی شده است؛ دارایی‌های موجود محیط FBX که در خروجی قبلی نبودند، همراه build فعلی کپی شده‌اند. انتخاب کاراکتر در حافظهٔ محلی ذخیره می‌شود. برای نصب رکورد در نسخهٔ Laravel، Seeder موجود پروژه از manifest جدید استفاده می‌کند:

```bash
php artisan db:seed --class=BuiltinCharacterSeeder
```

این دستور مطابق رفتار موجود Seeder، دریا را به‌عنوان پیش‌فرض فعال می‌کند. تست PHP جدید، نصب تکرارپذیر آیناز و فعال‌سازی او را پوشش می‌دهد؛ اجرای تست PHP به محیط دارای PHP و وابستگی‌های Composer نیاز دارد.

برای بازسازی و بررسی:

```bash
npm run build:ainaz:v14
npm run validate:characters:v14
npm run test:ci
npm run validate:final
npm run validate:ui-layers
npm run build
node tools/export_static.mjs --out=../playable
npm run validate:build
node tools/check_ainaz_v14.mjs
```

وابستگی‌های تصویر در `tools/requirements-character-art.txt` ثبت شده‌اند. تست مرورگر به Playwright و Chromium نیاز دارد؛ متغیرهای `DEMIAN_PLAYWRIGHT_MODULE` و `DEMIAN_BROWSER_EXECUTABLE` برای استفاده از نصب موجود پشتیبانی می‌شوند. گزارش واقعی بررسی‌ها در `verification.json` و `browser-checks.json` است. آزمون مرورگر با ابعاد موبایل شبیه‌سازی می‌شود؛ کارایی تلفن فیزیکی اندازه‌گیری نشده است.

ساختار دیتابیس، migrationها، `.env` و Dockerfile تغییری ندارند. ZIP اصلاحات شامل فایل‌های افزوده و اصلاح‌شده است. دو bundle قدیمی زیر با خروجی جدید جایگزین شده‌اند و در Git حذف شده‌اند؛ هنگام نصب دستی ZIP می‌توان آن‌ها را از مسیرهای زیر پاک کرد:

```text
playable/build/assets/app-BGJksTsx.js
playable/build/assets/app-crGsLucg.css
```
