# Phase 10 — Personal Progress Rewards

A versioned, private, nonfinancial projection of trusted sealed weekly bests, per player/game/rules version. No client score, timer, claim route, or arbitrary account selector. Verified phone must predate the run. Initial three distinct settled weeks calibrate; goal is maximum previously sealed score + max(25, ceil(5% of best)). Lower results, ties, inactivity and repeated runs never reduce the high-water mark; only one record per player/game/week; a strict new high is a record and a goal-reaching high earns personal-breakthrough once. No coupon, discount, XP conversion or financial budget commitment (budget zero). Scores at ceiling have no unreachable goal. Actual score improvement is not proof of human skill, particularly where weekly seeds vary; thresholds need pilot calibration.

The settlement mutex row is locked before the period row, serializing different week seals without locking players (preserves completion's player/run → period lock order). Projection is in the same transaction as weekly results, with source checksum and policy version. Late older seals preserve historical score but receive no badge if a newer week is already included. No inference/backfill of pre-rollout weeks. Goal comparison is against already sealed evidence at settlement time; the next-goal preview can advance if another historical week seals. Version changes start a new baseline; historic versions remain available via private privacy export, not combined. Cascade erasure removes personal progress. No public endpoint or new identifying data.

GET /api/v1/arcade/player/progress?game=dino-run is rate-limited private no-store, authenticated identity only, validates game allowlist. Latest sealed rule version, best score, number of distinct weeks, next target, badge count, last 12 points. Persian leaderboard details panel with accessible meter graph and textual scores, no client-side award, no offline synthesis. Existing live personal best remains distinct from sealed recognition. Reset on account change/close and discard stale responses.
