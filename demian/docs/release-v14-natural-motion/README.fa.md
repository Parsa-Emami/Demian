# اصلاح ریتم دویدن و پرش کاراکترها

دویدن تیام با زمان‌بندی نگار، ستایش، دریا و اوزودی هماهنگ شده است. کلیپ تیام ۱۶ پوز دویدن در دو ردیف دارد؛ منابع دیگر ۸ پوز دارند. اکنون زمان‌بندی، تعداد چرخه‌های پوز را لحاظ می‌کند تا تعویض سریع دست‌وپا ایجاد نشود. ریتم عمومی دویدن و sprint نیز ملایم‌تر و متناسب با سرعت حرکت پخش می‌شود.

در تست واقعی Dino Run، ضریب پخش دویدن تیام حدود 0.492 و برای چهار کاراکتر دیگر حدود 0.985 است. با لحاظ دو چرخهٔ تیام، آهنگ حرکت پاها برابر است. نسبت به پخش قبلی تیام در همین سرعت، سرعت تعویض پوزها حدود ۶۰ درصد کاهش یافته است.

پرش اکنون فریم‌های واقعیِ فشار پا، جمع‌شدن دست‌وپا در اوج و بازشدن پاها در فرود را به ترتیب نمایش می‌دهد. پیشرفت کلیپ با سرعت عمودی بدن هماهنگ است؛ کلیپ صعود زود تمام و ثابت نمی‌شود و کلیپ اوج از انتهای کلیپ قبلی شروع نمی‌شود. پوزهای آماده‌سازیِ روی زمین و ایستادنِ پس از فرود، داخل پرواز پخش نمی‌شوند. فریم فرود، کلیپ مستقل خودش را دارد.

مسیر مشترک زمان‌بندی در Canvas و SpriteCharacter استفاده می‌شود. جابه‌جایی walk/run/sprint مرحلهٔ حرکت پا را حفظ می‌کند، حتی وقتی تعداد چرخه‌های دو کلیپ متفاوت است. تغییر سرعت پخش، پیشرفت داخل فریم را حفظ می‌کند. تناسب بدن در بسته‌های V14 ثابت می‌ماند و حرکت اندام‌ها از پوزهای اسپرایت نمایش داده می‌شود.

اطلس‌های هر پنج نسخهٔ desktop، mobile، compact، runtime و lite و manifest انیمیشن‌های همهٔ کاراکترها به‌روز شده‌اند. درخواست اطلس، cache را بازاعتبارسنجی می‌کند تا تنظیمات زمان‌بندی قبلی باقی نماند. ابزار ساخت تصاویر نیز قرارداد جدید را تولید می‌کند. فایل‌های تصویری، قوانین برخورد و فیزیک جابه‌جایی تغییر نکرده‌اند.

## بررسی‌ها

- ۲۷۷ تست JavaScript پاس شده است.
- هر ۲۵ بستهٔ گرافیکی معتبر است.
- تست مرورگر در پنج اندازهٔ 320×568، 390×844، 844×390، 768×1024 و 1440×900 پاس شده است.
- انتخاب، سرخوردن و پرش با ورودی واقعی برای هر پنج کاراکتر بررسی شده است. نمونه‌های ثبت‌شده، ادامهٔ حرکت فریم‌ها در صعود، اوج و سقوط را نشان می‌دهند.
- حرکت و پرش تیام در کافه و انتخاب مشترک بین بازی‌ها نیز پاس شده است.
- ساخت Vite، بررسی لایه‌های UI و اعتبارسنجی bundle اتمیک موفق بوده‌اند.

نتایج در `verification.json`، `browser-checks.json` و `js-tests.txt` ثبت شده‌اند. تست مرورگر، ابعاد موبایل را شبیه‌سازی کرده است.

## بازتولید تغییرات زمان‌بندی

```bash
python3 tools/retime_character_animation_v14.py
npm run test:ci
npm run validate:characters:v14
npm run build
node tools/export_static.mjs --out=../playable
npm run validate:build
```

تغییرات ساختار دیتابیس، migration، `.env` و Dockerfile در این اصلاحات وجود ندارد.
