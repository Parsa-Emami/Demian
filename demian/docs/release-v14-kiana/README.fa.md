# کیانا در دمیان

کیانا (`KIANA / کیانا`) بلافاصله بعد از زهره در فهرست انتخاب کاراکتر قرار دارد. موهای بلند قهوه‌ای تیره با چتری یک‌طرفه، سویشرت زغالی، شلوار تیره و کفش مشکی از تصویر مرجع کیانا گرفته شده‌اند. تناسب بدن و محور پا `(0.5, 0.94)` با الگوی V14 دریا تنظیم شده‌اند.

شیت‌های منبع شامل هشت نمای ایستادن، چشمک، راه‌رفتن، دویدن، پرش، فرود، سرخوردن و ژست دو انگشتی برد هستند. زاویهٔ سه‌رخ در فریم‌های راه‌رفتن با پرش هم‌خوان شده است. نسخه‌های چپ و راست حرکت طبق نگاشت جهت‌های V14 در بازی فراخوانی می‌شوند. شیت‌ها و SHA-256 ورودی‌ها در [source-v14](../../public/assets/characters/kiana/source-v14) ثبت شده‌اند.

## بازسازی

دستورها از پوشهٔ `demian` اجرا می‌شوند.

```sh
python3 tools/build_character_pack_v14.py --characters kiana
python3 tools/build_runtime_character_packs.py --characters kiana --report docs/release-v14-kiana/runtime-packs.json
npm run validate:characters:v14
npm run build:static
```

## نتیجهٔ آزمون

- هر شش بستهٔ کیانا و مجموع ۱۵۰ جفت اطلس و تصویر برای ۲۵ کاراکتر اعتبارسنجی شدند. بیشینهٔ ارتفاع سرخوردن کیانا در آزمون هندسه ۴۴٫۵۴ پیکسل با حد ۴۶ پیکسل بود. مشخصات بسته‌های اجرایی در [runtime-packs.json](runtime-packs.json) ثبت شده است.
- در Chromium با رندر نرم‌افزاری و نماهای ۳۹۰×۸۴۴ و ۱۴۴۰×۹۰۰، کارت کیانا بعد از زهره و ماندگاری انتخاب پس از بارگذاری دوباره تأیید شد. اطلس کیانا در Open World، Dino Run، After Hours و Café Rush بارگذاری شد. پرش و عبور از مانع پرنده با سرخوردن لمسی و کیبورد در Dino Run پاس شدند.
- در Open World هر چهار حرکت با ورودی لمسی و بستهٔ Lite در نمای ۳۹۰×۸۴۴ آزموده شدند. جدول، میانهٔ ارتفاع سیلوئت هر حرکت و بیشترین فاصلهٔ فریم زمینی تا محور پا را بر حسب CSS پیکسل نشان می‌دهد.
