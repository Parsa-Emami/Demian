# ارسل در دمیان

ارسل بر اساس تصویر `IMG_20261022_122855_548.jpg` ساخته شده و به فهرست مشترک انتخاب شخصیت، دنیای کافه و Dino Run اضافه شده است. انتخاب او پس از رفرش حفظ می‌شود. موهای مشکی مرتب، سبیل، لباس تیره، کراوات طرح‌دار و نشان پشت پیراهن در منابع طراحی ثبت شده‌اند.

## گرافیک و حرکت

- ۶۸ حالت کلیدی منبع، ۶۷۲ نام فریم و ۲۴ حالت انیمیشن با همان قالب V14 بازی.
- بسته‌های desktop، mobile، compact، runtime و lite همراه با پیش‌نمایش، اطلس و فایل‌های هویت و حرکت.
- جهت‌های هشت‌گانهٔ ایستادن؛ راه‌رفتن، دویدن، جهش، سقوط، فرود، سرخوردن پایین، دست‌تکان‌دادن و شادی.
- چهار حالت مستقل سرخوردن از ردیف دوم منبع برای حفظ فاصله از مانع پرنده؛ حرکت پرش و برخوردها از فیزیک مشترک بازی استفاده می‌کنند.
- runtime با ۳۱۶ سلول و ۱۱٫۲۵ MiB حافظهٔ تصویر بازشده؛ lite با ۲۳۹ سلول و ۳٫۷۵ MiB.

## مسیرها

منابع و خروجی گرافیک: `public/assets/characters/arsal/` و نسخهٔ همسان در `playable/assets/characters/arsal/`.

پرامپت‌های کامل ساخت با ابزار داخلی imagegen: `art-prompts.json`. تصویر مرجع: `source-v14/reference.jpg`. تنظیمات استخراج و مقیاس: `source-v14/layout.json`.

## استفاده و بازسازی

از منوی انتخاب کاراکتر، «ARSAL / ارسل» را انتخاب کنید؛ سپس کافه یا Runner را شروع کنید. کنترل‌های حرکت و پرش همان کنترل‌های سایر شخصیت‌ها هستند.

برای بازسازی بسته‌ها از داخل `demian`، دستور `npm run build:arsal:v14` و برای خروجی اجرایی `npm run build:static -- --out=../playable` را اجرا کنید. نسخهٔ Laravel از `BuiltinCharacterSeeder` موجود برای ثبت یا ارتقای رکورد قدیمی ارسل استفاده می‌کند.

## بررسی

۳۱۱ تست JavaScript، هفت تست CharacterManager در PHP و بررسی ۴۵ اطلس پاس شدند. تست مرورگر Chromium در ابعاد 390×844 و 1440×900 انتخاب از رابط، پیش‌نمایش، حرکت و پرش کافه، جهش Runner، عبور از پرنده با سرخوردن لمسی و کیبورد و حفظ انتخاب پس از رفرش را بررسی کرده است. این بررسی موبایل شبیه‌سازی مرورگر است؛ آزمایش دستگاه فیزیکی انجام نشده است.

نتایج: `verification.json`، `browser-checks.json` و `runtime-packs.json`.
