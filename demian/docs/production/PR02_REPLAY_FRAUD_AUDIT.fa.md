# PR 02 — پایش تقلب و اعتبار تصمیم انسانی

این PR موتور Replay سرور را بازنویسی نمی‌کند؛ قوانین امتیازدهی و جایزه را تغییر نمی‌دهد. امتیاز تنها با اعتبارسنجی Replay قبلی تولید می‌شود.

- دو Run تأییدشده با بازه زمانی هم‌پوشان برای یک `player_id` یک هشدار قابل‌ممیزی `overlapping_verified_runs` می‌سازند. این مورد **اتهام قطعی تقلب نیست**؛ خصوصاً در محیط کافه/دستگاه مشترک ممکن است رخ دهد و فقط برای بررسی انسانی نمایش داده می‌شود.
- فعال یا غیرفعال‌کردن مشاهده خودکار سیگنال‌ها، Hold موقت و دستیِ تأییدشده توسط Super Admin را دور نمی‌زند. انقضا و رفع Hold با روال فعلی انجام می‌شود.
- امتیازها، رتبه‌ها و کوپن‌ها توسط سیگنال جدید حذف یا مسدود نمی‌شوند؛ فقط شخص دارای نشست معتبر و تأیید مجدد می‌تواند عملیات محدود را ثبت کند.
- آزمون‌ها باید نشان دهند ثبت سیگنال فقط به‌صورت غیرمالی انجام می‌شود و Hold دستی در حالت خاموش‌شدن مشاهده نیز همچنان اجرا می‌شود.
- این مرحله اصلاً به‌تنهایی ضدتقلب کامل نیست. تأیید امنیت جوایز واقعی نیازمند بازی روی دستگاه حقیقی، بررسی حملات Replay، آزمون هم‌زمانی روی MySQL و پذیرش مستقل است.

قابلیت `DEMIAN_ANTICHEAT_ENABLED` در محیط Production **تغییر نکرده** است.
