# نقشهٔ دمیان بر پایهٔ FBX

نقشهٔ فعال Open World از فایل ارسالی `دمیان .fbx` بازسازی شده است. فایل اصلی بدون تغییر، به‌صورت gzip در چهار بخش `sources/demian-cafe.fbx.gz.001` تا `.004` نگه‌داری می‌شود. ابزار واردکننده این بخش‌ها را خودکار ترکیب می‌کند؛ بایت‌های فایل اصلی تغییر نکرده‌اند؛ SHA-256 آن در گزارش تبدیل و دادهٔ نقشه ثبت شده است.

- ۱۱٬۶۰۵ مش سطح‌دار، ۱٬۵۶۳ سطح NURBS و ۹۲۹ سطح Trim NURBS تبدیل شده‌اند. ۱۱ مش منبع سطح قابل مثلث‌بندی ندارند؛ منحنی‌های ساخت و دوربین‌های نرم‌افزار طراحی وارد رندر بازی نمی‌شوند.
- مدل GLB حدود ۵۹۸ هزار مثلث دارد و بر اساس متریال در ۱۱۳ بخش ادغام شده است. تصاویر موجود در فایل درون GLB جاسازی شده‌اند؛ بازی مسیرهای کامپیوتر طراح را درخواست نمی‌کند.
- واحد منبع متر و محور قائم Z است. تبدیل مشترک: `x = -(sourceX + 48.5125) × 4`، `y = sourceZ × 4` و `z = (sourceY − 43) × 4`.
- بازی از تصویر ارتوگرافیکِ مدل و کاراکترهای موجود استفاده می‌کند. این تصویر حدود ۱۱۰ کیلوبایت است و از بارگیری مدل بزرگ در شروع جلوگیری می‌کند. گرافیک کاراکترها دوباره طراحی نشده است.
- مدل سه‌بعدی کامل، همراه با چرخش، زوم، جابه‌جایی، سقف و نشان موقعیت بازیکن، از دکمهٔ «نمای سه‌بعدی» در نقشه باز می‌شود. مدل فشرده حدود ۱۱٫۲ مگابایت است و فقط هنگام باز شدن این بخش بارگیری می‌شود.
- ۳۱۷ مستطیل برخورد از تصویر اشغال هندسه استخراج شده‌اند. تفکیک شبکهٔ برخورد ۹ سانتی‌متر در واحد منبع است؛ جزئیات رندر گرد نشده‌اند. ارتفاع نمونه‌گیری از ۱۵ سانتی‌متر تا ۱٫۷ متر است.
- فضاهای بستهٔ موجود در مدل، بسته باقی مانده‌اند. هیچ درگاه فرضی داخل دیوار ایجاد نشده است. اتاق‌های خالی مدل هم در نمای کامل حفظ شده‌اند.
- شروع کاراکترها، مسیر اصلی، مقصدهای سفر سریع، NPCها و نقاط حالت‌های آرشیوی با هندسهٔ جدید هماهنگ شده‌اند. مختصات ذخیره‌های قدیمی به مقصد معتبر متناظر منتقل می‌شود؛ شناسه‌های کاراکتر و مقصدهای بازشده حفظ می‌شوند.

## بازسازی

نیازمندی‌های توسعه: Node، Python، بسته‌های `tools/fbx/requirements.txt` و Playwright/Chromium. این ابزارها در اجرای سایت لازم نیستند.

```bash
cd demian
npm ci
python3 -m pip install -r tools/fbx/requirements.txt
npm install --no-save --package-lock=false playwright
npx playwright install chromium
npm run import:cafe:fbx
npm run test:ci
npm run build:static
npm run test:cafe:browser
```

برای مرورگر یا Playwright نصب‌شده در مسیر دیگر، متغیرهای `DEMIAN_BROWSER_EXECUTABLE` و `DEMIAN_PLAYWRIGHT_MODULE` پشتیبانی می‌شوند. `DEMIAN_SITE_ROOT` مسیر خروجی سایت و `DEMIAN_FBX_QA_DIR` مسیر گزارش مرورگر را تغییر می‌دهد.

فایل‌های `*.work.*` و GLB خام، خروجی‌های میانی هستند. خروجی‌های قابل انتشار، `floorplan.webp`، `cafe.glb.gz`، `import-report.json` و دادهٔ `FbxCafeData.js` هستند. بازسازی به فایل منبع دقیق و نسخه‌های ابزار نیاز دارد؛ نسخه‌های نصب‌شده در گزارش اعتبارسنجی ثبت می‌شوند.

## اعتبارسنجی

تست‌های منبع: حفظ SHA-256 فایل اصلی، وجود NURBS و Trim NURBS در خروجی، سلامت GLB، متناهی بودن مختصات و نرمال‌ها، تصاویر داخلی، تبدیل مختصات، کران دقیق نقشه، مسیرپذیری تمام نقاط تعاملی، مهاجرت ذخیره‌ها و هم‌ترازی کلیک/بزرگ‌نمایی نقشه.

تست مرورگر روی نسخهٔ خروجی و مسیر `/Demian/` انجام می‌شود: دسکتاپ، نمای موبایل، سفر سریع، نقشه، کنترل زوم، باز شدن مدل، چرخش، سقف، بستن نما و رفتار هنگام نبودن مدل یا تصویر نقشه. این بررسی شبیه‌سازی مرورگر است؛ اندازه‌گیری روی گوشی واقعی انجام نشده است.

انتشار اصلی با workflow موجود `deploy-demian-pages.yml` از سورس `demian` ساخته می‌شود. بستهٔ نصب‌شدهٔ برنامه همچنان از نسخهٔ ۱۴ کاراکترها استفاده می‌کند؛ نسخهٔ هندسهٔ جهان به ۵ ارتقا یافته است. دیتابیس، migration، `.env` و Dockerfile تغییری نکرده‌اند.
