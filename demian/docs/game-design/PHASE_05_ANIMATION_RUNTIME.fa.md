# فاز ۵A — موتور انیمیشن دمیان

## تغییرات سورس
- یک قرارداد انتقال snapshot بین CanvasCharacterAvatar و SpriteCharacter: نام حالت، موقعیت کسری، فاز قدم، تعداد چرخه، نرخ، جهت، حالت پایان و وضعیت حرکت مادر حفظ می‌شوند. انتقال کیفیت به خودی خود رویداد تماس پا تولید نمی‌کند.
- جهت‌هایی با تعداد فریم متفاوت بدون پرش فاز remap می‌شوند. restart نمونه قبلی را پاک می‌کند؛ interpolation زمان‌بندی واقعی از چند wrap عبور می‌کند. sample فقط خواندنی است.
- fallback اعلام‌شده اولویت دارد؛ نبود fallback دیگر به صورت ناخواسته همه aliasها را به idle هدایت نمی‌کند. حلقه fallback محدود است؛ combat بازنشسته بازنمی‌گردد.
- ورودی زمان/نرخ/فاز نامعتبر محدود می‌شود؛ سرعت نمایشی برای فاصله واقعی صفر، cadence صفر دارد. جابه‌جایی ناگهانی بدون سرعت صریح به‌عنوان راه رفتن محاسبه نمی‌شود.
- progress پیوسته برای حرکت مادر، بدون تغییر progress قدیمی rendererهای دیگر؛ فیزیک، hitbox، backend، امتیاز و قواعد replay دست‌نخورده‌اند.

## رگرسیون
Phase5AnimationRuntime.test.js شامل سناریوهای انتقال Lite→Runtime برای ۱۸ شخصیت، پایان one-shot، جهت متفاوت، چند wrap، fallback، ورودی نامعتبر و teleport است. تست‌های قبلی MasterMotion، NaturalLocomotion، SmoothCharacterLocomotion، CharacterFrameBlend و SpriteMemoryLifecycle باید همچنان پاس شوند. CI ساخت static و مرورگر و بودجه حافظه را اجرا می‌کند. فعلاً شواهد اجرای محلی و دستگاه فیزیکی در دسترس نیستند؛ هیچ نتیجه ساخت یا پذیرش انسانی جعل نشده.

## حدود فاز
هیچ PNG، اطلس، pose تصویری یا rig هنری تازه ایجاد نشده است. وضعیت ۵B در [TD-ART-001](../technical-debt/TD-ART-001-ART-REBUILD.fa.md) باز است؛ بازسازی Art Bible و شخصیت‌ها، فریم‌های انتقال واقعی و بررسی هنری آن‌ها نیازمند Work است. خروجی `playable/` برای اصلاح runtime به ساخت Vite/Static نیاز دارد؛ GitHub Pages از سورس می‌سازد. نسخه tracked تا بازسازی صریح آن به عنوان خروجی قدیمی تلقی شود.
