# فاز ۱ — استاندارد اجرایی تجربهٔ هفت بازی

**مبنای اجرا:** فاز صفر PR #108، SHA پایه `ae84fe0`. **وضعیت:** کد و تست‌های فاز ۱ در شاخهٔ مستقل آمادهٔ پذیرش؛ تکمیل تجاری و پذیرش انسانی مستقل هستند.

## محدودهٔ اجرا

۱. یک منبع دادهٔ قابل آزمون برای هر هفت بازی به `resources/game/game-design-briefing-v1.json` اضافه شده است. هدف، سه گام آموزشی، کنترل لمسی/کیبورد، منحنی یادگیری از شروع تا مهارت، وضعیت تمرین/رقابت، نوع معیار امتیاز، راهکار بعد از شکست و تلاش مجدد برای هر بازی در آن تعریف شده‌اند.

۲. ماژول `resources/js/game/design/GameExperience.js` این داده‌ها را با استاندارد موجود `game-design-standard-v1.json` یکپارچه می‌کند و خروجی خواندنی به UI می‌دهد. اسکور، فیزیک و بذر چالش را تغییر نمی‌دهد.

۳. کارت انتخاب هر هفت بازی، هدف و راهنمای `details/summary` قابل دسترسی با کیبورد و لمس را نشان می‌دهد. متن‌ها HTML escape شده‌اند؛ لینک یا دکمهٔ جایزه/رقابتِ بدون اعتبار اضافه نشده است. نمایش پاسخ‌گو، focus-visible، reduced motion و forced colors دارد.

۴. نتایج بازی یک نکتهٔ کوتاه برای تلاش بعدی از قرارداد دریافت می‌کند؛ وجود یا نبود آن وضعیت تأیید سرور و کوپن را تغییر نمی‌دهد.

۵. قرارداد CI با تست JavaScript و تست مرورگر Chromium کنترل می‌شود: وجود هفت کارت، ۲۱ گام آموزشی، باز و بسته شدن راهنما با Enter، مستقل بودن نمایش راهنما از اجرای بازی، یکسان بودن شناسه‌های کاتالوگ/Registry/Score و حفاظت قواعد رقابت و جایزه.

**محدودیت مهم:** این فاز قواعد موجود را برای کاربر آشکار و قابل آزمون می‌کند، اما منحنی عددی برخورد، پاداش یا سختی بازی‌ها را عمداً تغییر نمی‌دهد؛ هر تغییر فیزیکی در Ranked به تغییر نسخهٔ مشترک JavaScript/PHP و تست بازپخش مستقل نیاز دارد. در این فاز نه اثبات برابری سختی بازی‌ها داریم و نه دادهٔ Playtest واقعی. ممیزی عددی، تست میدانی و اصلاح تعادل هر عنوان از نظر تجربهٔ واقعی همچنان نیازمند داده و پذیرش بعدی است.

## دروازه‌های پذیرش

- `npm run test:ci`, `npm run validate:final`, `npm run build:static`, `npm run validate:static-assets`, `npm run validate:build`.
- ماتریس PHP/MySQL و SQLite و Workflow مرورگر باید روی SHA **نهایی همین PR** موفق شوند.
- هر بازی باید هدف واضح، سه آموزش، مرحلهٔ تمرین و مهارت، پیام شکست/تلاش مجدد و تفکیک تمرینی از نتیجهٔ تأییدشده داشته باشد.
- هیچ پرچم جایزه، OTP، ضدتقلب و امتیاز سرور در این فاز تغییر نمی‌کند.
- آزمون فیزیکی iOS/Android و پلی‌تست ۲۰ نفره، پذیرش هنری V2 و استقرار API مستقل همچنان گیت بیرونی‌اند؛ هیچ نتیجه‌ای برای آن‌ها جعل یا فرض نمی‌شود.
