# Darya V11 Rebuild Patch

این پچ برای ادغام کاراکتر Darya بر اساس Sprite Sheet جدید طراحی شده است.

تغییرات:
- اضافه شدن مرجع گرافیکی Darya V11
- اضافه شدن قرارداد Atlas V11 با انیمیشن‌های:
idle, walk, run, jump, attack, win, hit_reaction, fail_comic, tap_interact
- آماده برای جایگزینی خروجی نهایی PNG/Atlas پس از برش دقیق فریم‌ها

نکته:
در نسخه نهایی باید sprite sheet نهایی تولیدشده از همین شیت مرجع جایگزین شود تا فریم‌های واقعی داخل بازی رندر شوند.
