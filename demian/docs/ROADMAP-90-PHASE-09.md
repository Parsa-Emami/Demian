# Roadmap 90+ — Phase 09 Skill-Based Leagues

## Policy skill-league-v1
Separate, non-financial projection of each newly sealed weekly replay-verified technical snapshot. Only phone ownership verified at or before the best run qualifies. Distinct verified phone accounts per game; at least 20 per game. Use 0–1000 midrank percentile (all tied = 500), one best qualified game per account; no sum across games. Use server-time and immutable source checksum. Thresholds Bronze 0, Silver 450, Gold 700, Legend 900. New/sparse cohort remains placement until a qualifying week. Immediate promotion after the qualified season settles. Demotion at most one tier after three qualifying results below current threshold minus 100; floor lifetime peak minus one tier. Missing/unqualified weeks never punish inactivity. High current result classifies upward before league rank is awarded. No player-chosen league, no client points, no IP/device heuristic. The starting level uses only earlier weeks finalized by the Tehran Saturday boundary, so a week sealed immediately after that boundary enters the following starting-level window; last result is shown separately. Finalized standings are not retroactively reassigned. No fabricated live rankings.

## Storage and API
Migration creates arcade_skill_seasons and arcade_skill_standings. Source and snapshot digests, deterministic ranks and order, one result per player/period. Atomic trusted seal with existing financial snapshot, no historical backfill by inference. Public /competition/leagues?league=bronze|silver|gold|legend|placement&week=YYYY-MM-DD&limit=1..50 defaults to latest finalized week; /player/competition/league is read-only bearer-private. Public payload does not expose player ID/run/phone. Privacy export includes league history; erasure anonymizes links and hides public entry without reranking. UI provides Persian league selector and current/last result. No offline spoofing; no tokens in local leaderboard storage.

## Rewards and constraints
Top three ranks of each qualified tier receive nonfinancial recognition (ties share rank). Existing globally budgeted/deduplicated coupon rules and payout gates are unchanged; no easier Bronze coupon or new financial commitment. Introducing league-specific discount quotas requires cost/budget approval and pilot calibration, separate frozen economics policy, and the same weekly one-identity cap; not enabled now. A verified phone is not proof of a unique person, erasure/new identity can reset classification, and midrank reflects cohort composition. No claims of perfect bot/sandbag prevention. Calibration, active-season provisional ranking, physical-host acceptance and actual coupon league allocation remain gates. All previous source PNG debt remains a mandatory production art gate; cPanel workflow explicitly refuses production until review evidence covers current roster hashes.

Tests: ties, minimum cohort, duplicate input, promotion/demotion/no inactivity penalty, anti-sandbag floor, verified phone before play, immutable seal and privacy, API inputs, auth, frontend request contract. Do not claim CI green until exact-head run succeeds.
