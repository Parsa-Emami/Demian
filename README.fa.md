# دمیان — نسخهٔ ۱۳ موبایل
این نسخه بر پایهٔ پروژهٔ ارسال‌شده ساخته شده است. فقط **Open World** و **Dino Run** در فهرست و ایستگاه‌های بازی فعال‌اند. کد بازی‌های قبلی برای توسعهٔ آینده حفظ شده است.

## اجرای سریع
Node.js 24 و npm لازم است:
```bash
cd demian
npm ci
npm run build:static
python3 -m http.server 8080 --directory _site
```
آدرس http://localhost:8080 را باز کنید. برای آزمایش با گوشی روی همان شبکه، به‌جای localhost از IP کامپیوتر استفاده کنید. خروجی باید با HTTP سرو شود؛ بازکردن مستقیم index.html با file:// مناسب نیست.
پوشهٔ **playable** داخل ZIP خروجی آمادهٔ همین نسخه است و با دستور زیر اجرا می‌شود:
```bash
python3 -m http.server 8080 --directory playable
```

## تغییرات
- محیط هر دو بازی با Canvas دوبعدی نمایش داده می‌شود. سرویس‌های منطقی موجود Open World و ذخیرهٔ پیشرفت حفظ شده‌اند.
- رانر: کاکتوس، پرنده، افزایش سرعت، پرش کوتاه/بلند، خم‌شدن، امتیاز و رکورد محلی، توقف، نتیجه و شروع دوباره.
- عمودی و افقی بدون اجبار به چرخاندن گوشی؛ جوی‌استیک در سمت چپ و چهار عمل اصلی در سمت راست.
- انتخاب کاراکتر به شکل پنل قابل اسکرول؛ فقط دریا، تیام و روناک که بستهٔ واقعی دارند نمایش داده می‌شوند.
- دریا V13: ۴۵۶ فریم در سه اندازه، چرخهٔ راه‌رفتن ۴۸ و دویدن ۶۴ فریم، پرش ۳۲ فریم، هندسه و اندازهٔ بدن ثابت؛ رفع برش کفش و ترکیب دو تصویر.
- فونت فارسی Vazirmatn محلی است؛ گذارهای رابط از Web Animations API استفاده می‌کنند.

## کنترل‌ها
| بازی | گوشی | کیبورد |
|---|---|---|
| Open World | جوی‌استیک، دویدن، پرش، تعامل، اکشن‌های بیشتر، نقشه | WASD / جهت‌ها، Shift، Space، E، M |
| Dino Run | نگه‌داشتن پرش برای ارتفاع بیشتر، خم‌شدن | Space / ↑ / W و ↓ / S |
| مشترک | توقف، انتخاب کاراکتر، خانه | Escape؛ P برای پنل کاراکتر |

## توسعه و بررسی
```bash
cd demian
npm run test:ci
npm run validate:final
npm run validate:ui-layers
python3 -m pip install -r tools/requirements-character-art.txt
npm run validate:darya:v13
npm run build:static
npm run validate:build
```
برای بازسازی گرافیک دریا: `npm run build:darya:v13`. منبع اصلی، ابزار تولید، atlas و خروجی‌ها داخل پروژه هستند.
راهنمای استاندارد شخصیت بعدی: `demian/docs/character-standards/MOBILE_CHARACTER_V13.fa.md`.
گزارش تست: `demian/docs/release-v13/QA.fa.md`.
این نسخه برای اجرای استاتیک به PHP یا دیتابیس نیاز ندارد. سورس Laravel نیز نگه داشته شده است. فایل‌های محیط و ساختار دیتابیس تغییری نکرده‌اند. اسکریپت نصب جدید دیتابیس را پاک یا بازسازی نمی‌کند.
مستندات فازهای قدیمی و اسکریپت‌های hotfix قبلی تاریخی‌اند؛ برای این نسخه از دستورهای همین راهنما استفاده کنید.
