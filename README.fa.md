# دمیان — نسخهٔ ۱۴

**نگار و بهینه‌سازی:** نگار، پوستر مرجع، اسپرایت‌های کامل و ابیلیتی «شکوفهٔ لبخند» با Q / لمس اضافه شده‌اند. کاراکترها دو کیفیت سبک اجرایی دارند؛ لود و انتخاب هم‌زمان اصلاح شده‌اند. مپ با جزئیات کمتر و کش رسم، چهار برابر مساحت قبلی دارد و ساختارش از سه ویدیوی کافه گرفته شده است. راهنما در [NEGAR-README.fa.md](NEGAR-README.fa.md) آمده است. سورس از commit `b7afcdd` شاخهٔ main گرفته شده است. بررسی: ۲۷۰ تست، ۲۰ اطلس، مرورگر در پنج اندازهٔ صفحه و سناریوهای لود کند/خراب پاس شده‌اند.

این ZIP کل پروژهٔ اصلاح‌شده را شامل می‌شود: سورس Laravel و جاوااسکریپت، تنظیمات ساخت، تست‌ها، تصاویر مرجع، منابع گرافیکی، اطلس‌های جدید، خروجی تولیدی و پوشهٔ آمادهٔ اجرای `playable`.

## اجرای نسخهٔ آماده

در پوشهٔ اصلی پروژه اجرا کنید:

```bash
python3 -m http.server 8080 --directory playable
```

سپس `http://localhost:8080` را باز کنید. برای گوشی روی همان شبکه از IP کامپیوتر استفاده کنید. این خروجی به PHP، دیتابیس یا سرویس تصویرسازی نیاز ندارد. `index.html` باید با HTTP سرو شود.

## تغییرات نسخهٔ ۱۴

- ستایش و اوزودی از روی تصاویر مرجع ارسالی ساخته شده‌اند و در انتخاب کاراکتر، Open World و Dino Run حضور دارند.
- اطلس دریا از ۴۵۶ به ۶۷۲ فریم رسیده است. هر سه کاراکتر یک قرارداد مشترک V14، جای پای ثابت، مقیاس یکنواخت و خروجی‌های desktop، mobile و compact دارند.
- دریا و پیشی در تمام حالت‌های حرکت همراه‌اند. اسلاید، حالت کوتاه و مستقلی است؛ تصویر ایستاده برای آن فشرده نمی‌شود.
- اوزودی هنگام دویدن بال می‌زند، در پرش بال‌ها را باز می‌کند و در اسلاید با بال‌های جمع‌شده و رو به عقب سر می‌خورد. فیزیک برخورد و پرش برای همهٔ کاراکترها یکسان است.
- تیام و روناک از فهرست، دارایی‌های اجرایی، NPCها، دیالوگ‌ها و seed اختصاصی حذف شده‌اند. انتخاب‌های قدیمی آن‌ها به دریا برمی‌گردد و API آن‌ها را به فهرست بازی برنمی‌گرداند.
- اکشن‌های نامرتبط از انتخاب دکمه‌ای و ورودی جهان حذف شده‌اند. فهرست بیشتر اکنون اسلاید، شادی، گفتگو و ذخیره است؛ کنترل‌های دویدن، پرش و تعامل حفظ شده‌اند.
- رانر دارای لایه‌های پارالاکس، آسمان رنگی، غروب و طلوع تدریجی، ماه و ستاره، پرندهٔ بال‌زن، کاکتوس و گردوغبار محدود است. چرخهٔ روز و شب ۹۰ ثانیه است.
- نمایش نرم، جزئیات چهره و بدن را حفظ می‌کند. سقف بافر رسم ۱٫۲۵ میلیون پیکسل است؛ سقف تراکم گوشی ضعیف ۱ و گوشی متعادل ۱٫۳۵ است. شش کاشی کوچک پس‌زمینه فقط یک بار رسم می‌شوند، پیش‌نمایش‌ها تصویر کوچک دارند و کش اسپرایت محدود است.

## ساخت از سورس

Node.js 24 و npm لازم‌اند:

```bash
cd demian
npm ci
npm run test:ci
npm run validate:final
npm run validate:ui-layers
python3 -m pip install Pillow
npm run validate:characters:v14
npm run build:static
npm run validate:build
python3 -m http.server 8080 --directory _site
```

برای به‌روزرسانی پوشهٔ آمادهٔ `playable` پس از تغییر سورس:

```bash
npm run build
node tools/export_static.mjs --out=../playable
```

برای بازسازی اطلس‌ها از منابع PNG موجود در پروژه:

```bash
python3 -m pip install -r tools/requirements-character-art.txt
npm run build:characters:v14
npm run validate:characters:v14
```

بازسازی اطلس به API تصویرسازی نیاز ندارد. پرامپت‌های دقیق و شیوهٔ ساخت منابع در `demian/docs/release-v14/art-prompts.json` نگه داشته شده‌اند. راهنمای معماری: `demian/docs/character-standards/MOBILE_CHARACTER_V14.fa.md`.

## استفاده با Laravel

سورس و تنظیمات Laravel حفظ شده‌اند. برای نصب جدید، محیط و دیتابیس را مطابق پروژه تنظیم و سپس Composer و migrationهای موجود را اجرا کنید. روی نصب موجود فایل محیط را جایگزین نکنید. پس از نصب وابستگی‌ها، برای نصب چهار کاراکتر V14 و حذف رکورد داخلی تیام و روناک اجرا کنید:

```bash
php artisan db:seed --class=BuiltinCharacterSeeder
php artisan optimize:clear
```

این seed جدول‌ها را بازسازی نمی‌کند، کاراکترهای سفارشی را نگه می‌دارد و دریا را پیش‌فرض فعال می‌کند. فایل‌های محیط و migrationهای نسخهٔ ورودی دست‌نخورده‌اند.

## بررسی نسخهٔ پایهٔ V14 پیش از افزودهٔ نگار

۲۵۴ تست جاوااسکریپت، اعتبارسنجی ۹ اطلس و ۶۰۴۸ فریم، ساخت Vite، بررسی رابط و اجرای مرورگر در پنج اندازه پاس شده‌اند. اسلاید با لمس واقعی شبیه‌سازی‌شده و عبور از پرنده برای هر سه کاراکتر بررسی شده است. گزارش و تصاویر در `demian/docs/release-v14/` قرار دارند.

مرورگر آزمایش Chromium با رسم نرم‌افزاری بوده است؛ نرخ فریم، باتری و دمای گوشی واقعی اندازه‌گیری نشده‌اند. ۵۷ فایل PHP از نظر نحو با parser بررسی شده‌اند؛ تست اجرایی Laravel به دلیل نبود PHP در محیط ساخت اجرا نشده است.

فایل‌های فازها، hotfixها و نسخه‌های قدیمی برای حفظ سورس ورودی باقی مانده‌اند و راهنمای این انتشار نیستند. فقط دستورهای V14 بالا را برای این نسخه استفاده کنید. پوشه‌های وابستگی قابل نصب و کش‌های موقت داخل ZIP قرار نگرفته‌اند؛ manifest و lockfileهای نصب موجودند.
